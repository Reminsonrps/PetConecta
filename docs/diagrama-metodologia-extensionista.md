# Diagrama da Metodologia do Projeto (com validacao via Google Form)

```mermaid
flowchart TD
    A[Diagnostico do problema na comunidade 20 dias] --> B[Definicao de objetivos e escopo]
    B --> C[Planejamento incremental por ciclos]
    C --> D[Implementacao tecnica do PetConecta]
    D --> E[Testes funcionais e ajustes internos]
    E --> F[Publicacao da versao para uso]
    F --> G[Coleta de feedback com usuarios e ONGs]
    G --> H[Validacao dos dados via Google Form]
    H --> I[Analise dos resultados coletados]
    I --> J[Refinamento de funcionalidades e documentacao]
    J --> K[Consolidacao das evidencias para entrega]

    I -- Necessita melhorias --> C
    I -- Objetivos atendidos --> K
```
